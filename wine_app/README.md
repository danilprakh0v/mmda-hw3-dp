# Вино в подборку

ДЗ-3 по курсу «Математические методы анализа данных». Прахов Данил, БПИ246.

Приложение развёрнуто в **Streamlit Community Cloud**:
[открыть «Вино в подборку»](https://mmda-hw3-dp-mfvysmmaj7arqxg5dmxvi5.streamlit.app).

[Репозиторий с ноутбуком и исходными данными](https://github.com/danilprakh0v/mmda-hw3-dp).

Приложение оценивает вероятность того, что вино получит не меньше 7 баллов у экспертов.
Используется обученный в ноутбуке пайплайн `StandardScaler → LogisticRegression`.
Порог 0.268889 выбран по F1 на внутренней валидации тренировочной выборки.

## Рекомендуемый браузер

Для проверки и демонстрации приложения рекомендуется актуальная версия **Google Chrome**.
При проверке желательно открыть все четыре вкладки, изменить порог и загрузить пример CSV.
Если после обновления приложения элементы отображаются некорректно, откройте ссылку в новой вкладке
или полностью обновите страницу.

## Запуск

Проверено на Python **3.14.8**. Из корня репозитория:

```bash
python3.14 -m venv .venv
source .venv/bin/activate
python -m pip install -r wine_app/requirements.txt
python -m streamlit run wine_app/app.py
```

При запуске из самой папки `wine_app` используйте `requirements.txt` и `app.py`.
Пути к модели и тестовым данным считаются от папки `app.py`.
Модель в приложении не переобучается.

## Оформление

Светлая тема использует молочный фон и приглушённые винные акценты, тёмная —
глубокий сливовый фон и пудровые оттенки. Выбор темы находится в меню **⋮**
в правом верхнем углу Streamlit (светлая, тёмная или системная).
Формы и таблицы используют штатные темы; цвета графиков определяются по теме браузерной сессии.

## Возможности

- Оценка одного вина по 12 признакам, включая переключатель красное/белое.
- Матрица ошибок, precision, recall, F1, ROC- и PR-кривые с текущим порогом.
- Предсказания для CSV и скачивание результатов; пример файла доступен в приложении.
- Диаграмма коэффициентов логистической регрессии после стандартизации.

Общий порог задаётся в сайдбаре. Если CSV содержит пропуски, неверные значения
или не содержит необходимых столбцов, выводится сообщение об ошибке.

## Кэширование

`st.cache_resource` сохраняет один экземпляр модели между перезапусками скрипта.
Модель используется только для предсказаний. Без этого декоратора `joblib.load`
читал бы модель с диска при каждом изменении порога.

`st.cache_data` кэширует таблицу `test.csv` и массив вероятностей, возвращая копии
данных. Порог не входит в аргументы `test_proba`, поэтому при движении слайдера
тестовые вероятности не пересчитываются. Аргумент `_model` исключён из хэширования;
изменение файла модели учитывается отдельным аргументом `model_revision`.

## Файлы

- `app.py` — код приложения.
- `style.css` — оформление интерфейса.
- `.streamlit/config.toml` — светлая и тёмная темы с винными оттенками.
- `model.joblib` — обученный пайплайн.
- `config.json` — порог и порядок признаков.
- `test.csv` — отложенная выборка с целевой переменной.
- `requirements.txt` — версии зависимостей приложения.

## Результаты

При пороге 0.268889: precision = 0.4739, recall = 0.6397, F1 = 0.5444,
ROC-AUC = 0.8135, AP = 0.5121. Подборка требует дальнейшей оценки сомелье.
Из-за пересечения одинаковых строк между train и test метрики могут быть завышены.
